# Workboard — shared design

Reference: user's own ERP prototype Variant C, read-only. Preserve Kanit, warm paper/surface, terracotta accent, 200px sidebar, 52px header and toolbar. Reports use a 180px project index with document content beside it, fine separators, restrained 12–15px text. Use the same shell for overview, Kanban, weekly report, calendar and access management. No hero or oversized dashboard tiles.

Calendar: month grid beside a daily agenda; collapse to stacked sections on narrow viewports. Meetings open in a right drawer with separate readable and editable tabs. Imported summaries keep their wording and are displayed as headings, lists, checklists, tables and quoted text. No invented meeting content, automatic decisions or automatic task creation. Admin-only access manager creates links into this same frontend.

Visual review limitation: browser unavailable in the implementation session. Responsive CSS is provided; actual browser inspection at 320/375/414/768px remains to be performed.
